# Asia Restaurant Mister Jin: sample page

Concept mock-up of a one-page website for the **Asia Restaurant Mister Jin** in Haag (Lower Austria), made by [Dual-Stack Studio](https://dualstackstudio.com).
It is **not the official website** of the restaurant and has not been published or approved by them.

- Static site, no build step and no tracking: `index.html`, `speisekarte.pdf` (the menu opened by the PDF buttons) and `assets/`.
- Dishes, prices, opening hours and phone numbers were transcribed from the restaurant's printed flyer and still need to be confirmed by the restaurant.
- Texts marked as to-do (yellow) are placeholders.
- The page asks search engines not to index it (`noindex`).

## View it

Open `index.html` in a browser, or use GitHub Pages (Settings, Pages, Deploy from branch `main`, folder `/ (root)`):
https://dual-stack-studio.github.io/Asia-Restaurante-Mister-Jin-Sample/
